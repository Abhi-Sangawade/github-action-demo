# DevOps Frontend Portfolio

This repository now contains a frontend portfolio website built with React and Vite.

## What it includes
- `index.html` and React components in `src/`
- `server.js` to serve the production build
- frontend portfolio sections for React, Angular, JavaScript, and DevOps
- a build pipeline using Node.js instead of Python

## Run locally

```powershell
npm install
npm run dev
```

## Build for production

```powershell
npm run build
npm start
```

## Docker

```powershell
docker build -t devops-portfolio:latest .
```

## Notes
- Python has been removed as the runtime for this portfolio site.
- This project is now focused on frontend languages and frameworks like React, Angular, and JavaScript.
